# Лабораторная работа 1.6

## Тема
Стилизация JavaFX-приложения с помощью CSS и добавление иконки приложения.

## Цель работы
Изучить способы оформления пользовательского интерфейса JavaFX с использованием каскадных таблиц стилей CSS и научиться добавлять иконку приложения.

## Описание проекта
Проект представляет собой настольное приложение «Электронный каталог книг», разработанное на языке Java с использованием JavaFX.

Приложение позволяет просматривать список книг, выбирать книгу для просмотра подробной информации, а также добавлять, редактировать и удалять записи.

## Выполненные задания
1. Создан файл `DarkTheme.css` для настройки внешнего вида интерфейса.
2. Изменено оформление таблицы книг, кнопок и текстовых элементов.
3. Настроены цвета текста, фона и заголовков для улучшения читаемости интерфейса.
4. CSS-стили подключены к основному окну и окну редактирования книг.
5. Добавлена иконка приложения в заголовок окна JavaFX.
6. Проверена работа приложения после внесения изменений.

## Используемые технологии
- Java
- JavaFX
- FXML
- CSS
- Maven
- IntelliJ IDEA
- Scene Builder

## Структура проекта
- `Launcher.java` — запуск приложения и настройка окон.
- `model/Book.java` — модель книги.
- `model/Author.java` — модель автора.
- `controller/BookOverviewController.java` — управление основным окном.
- `controller/BookEditDialogController.java` — управление диалоговым окном редактирования.
- `BookOverview.fxml` — интерфейс электронного каталога.
- `BookEditDialog.fxml` — интерфейс добавления и редактирования книг.
- `DarkTheme.css` — таблица стилей приложения.
- `images/book-icon.png` — иконка приложения.
- `pom.xml` — конфигурация Maven и зависимости проекта.

## Результат
В результате выполнения лабораторной работы внешний вид электронного каталога книг был изменён с помощью CSS. Настроены цвета текста, фона, таблицы и кнопок. Добавлена иконка приложения.

## Вывод
В ходе лабораторной работы были освоены основные приёмы стилизации интерфейса JavaFX с использованием CSS и способы подключения иконки приложения. Полученные навыки позволяют улучшать внешний вид настольных приложений и делать интерфейс более удобным для пользователя.
